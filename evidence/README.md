# Evidence

Place sanitized screenshots and other supporting evidence for the assessment in this directory.

Suggested organization:

```text
evidence/
├── hammal/
│   └── F-01/
├── seema/
│   └── access-control/
└── ayesha/
    └── xss/
```

For each test, include a short note describing the finding/test ID, date, local feature tested, steps shown and observed result.

**Before committing evidence, redact passwords, session tokens, cookies, authorization headers, personal information and any other secrets.** Do not upload raw ZAP responses containing authentication tokens.
